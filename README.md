
# ⚡ Electricity Bill Prediction System
Project link : https://electricitybillprediction-fgowykmryfmohaiqu3rwmn.streamlit.app/

## Overview

The Electricity Bill Prediction System is a Machine Learning web application that predicts a household's monthly electricity bill based on appliance usage, electricity tariff, location, and other relevant factors. The application also provides personalized energy-saving recommendations to help users optimize electricity consumption.

## Features

- Predicts monthly electricity bill using Machine Learning
- User-friendly web interface built with Streamlit
- Data preprocessing and feature engineering
- Supports multiple input parameters
- Provides energy-saving recommendations
- Real-time bill prediction

## Technologies Used

- Python
- Streamlit
- Scikit-learn
- Pandas
- NumPy
- Pickle

## Machine Learning Models Evaluated

- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor
- K-Nearest Neighbors (KNN)
- Support Vector Regression (SVR)
- AdaBoost Regressor

The best-performing model was selected for deployment.

## Dataset

The project uses the **Indian Household Electricity Consumption Dataset** containing features such as:

- Fan
- Refrigerator
- Air Conditioner
- Television
- Monitor
- Motor Pump
- Month
- City
- Electricity Company
- Monthly Usage Hours
- Tariff Rate
- Electricity Bill

## Feature Engineering

A new feature, **Total Appliance Load**, was created by combining the electricity usage of household appliances to improve model performance.
